# 🧾 Household Budget Organizer

## 💡 Overview  
The **Household Budget Organizer** is a web-based personal finance tool designed to help users manage their monthly income effectively.  
It allows you to define a total budget, allocate funds across different categories, track expenses, and visualize your spending with dynamic charts — all in an intuitive and modern interface.

---

## 🧰 Tech Stack
- **HTML5** – Semantic structure for accessibility and clarity  
- **CSS3** – Responsive and modern UI with custom themes  
- **JavaScript (Vanilla)** – Dynamic functionality and data persistence  
- **Chart.js** – Interactive bar charts for data visualization  
- **LocalStorage** – Saves user data locally for a seamless experience  

---

## 🚀 Main Features
✅ Define a **monthly income** and allocate it across custom categories  
✅ Add, edit, and delete expenses dynamically  
✅ Track **total spent, remaining balance, and usage percentage**  
✅ **Dark/Light theme toggle** with smooth transitions  
✅ **Interactive charts** showing spending vs. budget distribution  
✅ **LocalStorage persistence**, keeping data even after refresh  
✅ Fully **responsive design** for desktop and mobile users  

---

## 🧮 How to Use
1. Enter your **monthly budget** at the top of the page.  
2. Assign a percentage goal to each spending category.  
3. Add expenses with a short description and amount.  
4. Check your **progress bars and charts** to see where your money goes.  
5. Switch between **light and dark mode** anytime.
